# Stepper Leadscrew Measure

Измерение параметров шагового двигателя и ходового винта (шпильки).

## Структура проекта

- `01_calibration` — калибровка: сколько см проходит гайка за 1 оборот.
- `02_measure` — измерение расстояния между пластинами.

## Код №1: калибровка (сколько см проходит гайка за 1 оборот)

**ТЗ:** нажимаем кнопку на пине 6, и мотор делает ровно `REVS_TEST` оборотов
(при полном шаге это `REVS_TEST × 200` шагов). Затем мы линейкой измеряем путь
гайки по шпильке и вписываем его в `DISTANCE_CM`. После перезагрузки код считает
см на 1 оборот = `DISTANCE_CM / REVS_TEST`. Это число нужно для кода №2.

## Код №2: измерение расстояния между пластинами

**ТЗ:**

1. Щуп стоит на середине шпильки. Нажимаем кнопку на пине 6 (один раз),
   и мотор начинает вращаться.
2. Пока щуп не коснулся пластины, на пине 4 стоит `LOW`. При первом касании
   (на пине 4 появляется `HIGH`) направление меняется (`DIR_PIN` становится
   `HIGH`), и начинается подсчёт шагов.
3. При втором касании направление снова меняется, подсчёт останавливается.
4. По числу шагов считаем обороты и расстояние:
   - обороты = шаги / 200;
   - путь = обороты × `CM_PER_REV`.
   Результат выводится в Serial Monitor.
5. В конце мотор возвращает щуп на середину: проезжает половину посчитанного пути.
